You shouldn't need to know how video works.

People who build video workflows with an agent usually never learned FFmpeg, speech-to-text, or frame sampling. They copy a setup someone shared and hope the agent figures out the rest.

A strong agent usually works it out, after a detour. In our test, Claude Code without the plugin built a Python environment and downloaded a speech model before it could answer. Codex without it got two spoken-word questions wrong, guessing from the slides. Video Perception gives the agent a practiced way to look and listen, so it goes straight to the method that works.

Same agent, same computer, one plugin apart.

Eight everyday questions with exact answers: find a sentence, read a code on screen, find the dead air, spot a black screen, count the cuts. Each agent ran every question twice without the plugin and twice with it. With the plugin every agent answered all of them. Spoken and long-video questions got 2 to 18 times faster. Quick checks cost a few seconds on some agents and got faster on DeepSeek Harness.

Prompts, videos, grading and every agent's commands are in evals/perception. Run it yourself on your own agent.

Set it up in three steps.

  1. Install the tool

    It needs FFmpeg. On a Mac with Homebrew, run the first line too.

    brew install ffmpeg imagemagick whisper-cpp
curl -fsSL https://raw.githubusercontent.com/opus-pro/video-perception/main/install.sh | sh
video-perception setup --profile basic

    The last command only checks your computer and tells you what is missing. It never installs anything.
