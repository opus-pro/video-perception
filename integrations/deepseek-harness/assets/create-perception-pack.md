# Create a Video Perception pack

Use this when the user wants to preserve a recurring way of reading video.
Create a `video-perception.strategy/v1` manifest for technical evidence
collection and a `video-perception.knowledge-pack/v1` manifest plus Markdown
for interpretation guidance.

Keep the pack under the project `.video-perception/extensions/` directory by
default. Give it a lowercase namespaced id. Do not copy or redistribute source
tutorials, model weights, datasets, or proprietary documentation without an
appropriate license. Validate the directory with
`video_perception_validate_extension` and test it on safe media before use.
